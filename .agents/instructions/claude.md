- To pass information to another Claude Code session (debriefs, status, follow-ups), prefer native cross-session messaging over tmux. Find the target with `ListAgents` and send with `SendMessage` (load it via ToolSearch `select:SendMessage` if deferred). Each `ListAgents` row shows the peer's tmux location (`tmux <session>:@<window-id>.%<pane>`), so you can map a tmux window name to a session by resolving the window id with `mux list tabs --all`. Fall back to `mux paste` only when no listed peer matches, the target is a pi or other non-Claude session, or `SendMessage` fails. Never type into a Claude session with `mux send`/`mux paste` when a native send is possible.
